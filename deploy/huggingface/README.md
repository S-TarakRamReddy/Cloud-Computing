# Cloud-Based Credit Card Fraud Detection

An explainable fraud-scoring service: a calibrated XGBoost model behind a FastAPI service with a dashboard that shows the verdict, the reasons for it, a what-if explorer, and a built-in Monitoring pane.

This Space is deployed automatically from the GitHub repository
[S-TarakRamReddy/Cloud-Computing](https://github.com/S-TarakRamReddy/Cloud-Computing) by a GitHub Actions job, after the tests, Docker build, monitoring check, image publish and staging check have passed on `main`. Do not edit files here; changes are overwritten on the next deploy.

The data is a public, anonymised dataset. This is a demonstration, not a production system.
